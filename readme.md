# Настройка Firebase для FUNDING / WATCH

Конфигурация вашего проекта (`funding-watch-3c7cb`) уже встроена прямо в код `index.html` — ничего копировать и вставлять на странице не нужно. Осталось включить нужные настройки в самой консоли Firebase (это займёт пару минут).

> **Важно:** `apiKey` в конфиге — не секретный ключ, его можно спокойно хранить в открытом клиентском коде. Реальная защита данных обеспечивается правилами Firestore и списком включённых провайдеров входа, а не сокрытием конфига.

---

## 1. Включить вход по email и паролю (Authentication)

1. Откройте проект [funding-watch-3c7cb](https://console.firebase.google.com/project/funding-watch-3c7cb) в консоли Firebase.
2. В левом меню выберите: **Build** → **Authentication**.
3. Перейдите на вкладку **Sign-in method** → нажмите **Add new provider** → выберите **Email/Password**.
4. Включите первый тумблер **Email/Password** → нажмите **Save**. 
   *(Второй тумблер «Email link — passwordless sign-in» включать не нужно, сайт его не использует).*
5. По умолчанию Firebase не требует подтверждения email при регистрации — можно входить сразу после создания аккаунта.

---

## 2. Создать базу данных Firestore

1. В левом меню выберите: **Build** → **Firestore Database** → нажмите **Create database**.
2. Выберите регион (любой ближайший к вам, **менять потом нельзя**).
3. Режим запуска: можно выбрать **Start in test mode**, но перед тем как оставить это надолго, **обязательно** настройте правила безопасности из шага 3 ниже.

---

## 3. Настроить правила безопасности Firestore

По умолчанию (или в тестовом режиме) база либо закрыта, либо временно открыта всем — оба варианта не годятся для постоянной работы. Нужно ограничить доступ так, чтобы каждый пользователь видел и изменял только свои настройки и журнал.

1. Перейдите в **Firestore Database** → вкладка **Rules**.
2. Полностью замените содержимое редактора на следующие правила:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Разрешаем чтение и запись только если пользователь авторизован 
    // и его UID совпадает с UID в пути документа
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
